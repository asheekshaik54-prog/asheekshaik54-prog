### 🧭 1. Career Compass
**AI Career Intelligence & Skill Improvement Platform**

A team project focused on helping learners identify skill gaps, improve technical abilities, and follow personalized learning paths.

- Designed around a continuous assess → diagnose → improve → verify workflow.
- Focuses on Python, SQL, and DSA skill assessment.
- Includes targeted practice and AI mock interview capabilities in the project design.
- Explores explainable next-step recommendations for learners.

**Tech stack:** React, Tailwind CSS, FastAPI, Python, Ollama, RAG, n8n, SQLite, PostgreSQL, and MongoDB.

### 🏥 2. MediTrust AI
**Secure Federated Edge AI Healthcare Platform Using Blockchain**

A B.Tech major project exploring privacy-preserving heart disease prediction through federated learning simulated across three hospitals.

- Explores local model training without sharing raw patient data.
- Uses federated learning concepts with Flower.
- Plans blockchain-based model integrity verification using SHA-256 hashes.
- Plans SHAP-based explainability for model predictions.

**Tech stack:** React, Tailwind CSS, FastAPI, TensorFlow, Scikit-learn, SHAP, MongoDB, Docker, Solidity, and Ethereum.

*Blockchain verification and explainability features should be considered planned until implemented and tested.*

### 🛡️ 3. EVM Smart Contract Analyzer
**Real-Time Smart Contract Bytecode Decompiler & Reentrancy Symbolic Execution Engine**

A personal project focused on analyzing Ethereum Virtual Machine bytecode and investigating reentrancy vulnerabilities.

- Focuses on converting compiled EVM bytecode into a readable representation.
- Explores contract execution paths through symbolic execution.
- Targets the analysis of reentrancy-related security weaknesses.

**Tech stack:** Python, Solidity, and Ethereum.

### 🏦 4. Loan Approval Prediction
**Bank Loan Prediction Using Machine Learning**

A machine learning project that predicts whether a bank loan application will be approved.

- Uses Python and machine learning techniques.

**Tech stack:** Python, Machine Learning.
